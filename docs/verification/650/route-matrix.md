# FallStack route and access matrix

Baseline `0a3cc7faed6c211f3034288931c99b84f57383d0` and the audited runtime-equivalent
`main` tree. Roles and ownership below describe the intended boundary and identify
where a handler uses a broader policy. Pending security findings are recorded in
private repository advisories.

## Rendered pages and server actions

The matrix covers all 56 page files. Groups share the same guard. The public
company page is inside a route group named `(protected)`. That layout applies
dynamic rendering and document metadata. Access is decided by the page and
its nested guards.

| Page or action                                                                                                                                                                      | Guard and data boundary                                                                                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/event/[language]`, `/about`, `/privacy-policy`, `/terms`                                                                                                                          | Public. Event page validates language and includes public edition data.                                                                                                                                                    |
| `/company/[name]`                                                                                                                                                                   | Public active company, rank permits an internal page, company has a profile.                                                                                                                                               |
| `/login`, `/password-reset`, `/password-reset/confirm`, `/signup/employee`                                                                                                          | Public landing/compatibility pages. ## Other HTTP entry points

| Surface                                                                      | Access and data boundary                                                                                                                                                                                                                 |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/robots.txt`, `/sitemap.xml`, `/manifest.webmanifest`                       | Public metadata. Sitemap uses public active company data; the staging variant omits indexable entries.                                                                                                                                   |
| `/_next/image`, `/_next/static/*`, `/assets/*`, icons, service-worker assets | Public framework and checked-in assets. The image optimizer has configured HTTPS host and path patterns.                                                                                                                                 |
| `GET /metrics`                                                               | Separate Prometheus listener. Network-scoped with no application session. Other methods/paths return 404.                                                                                                                                |
| OFF-SEASON and public PREPARATION                                            | Nginx serves only the static landing, worker, scripts, CSS and specified images with GET/HEAD.                                                                                                                                           |
| Private PREPARATION gateway                                                  | Requires a client certificate and revocation list at the gateway, plus the app's own guards. Proxies the admin and scanner pages, selected auth/admin/check-in APIs, limited action refresh/toggle, protected CV files and static media. |
