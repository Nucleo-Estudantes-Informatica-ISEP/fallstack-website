# Contribution Workflow

For every requested task:

1. Create a new branch from `dev` named `chore/<task>`, where `<task>` is a concise kebab-case task description.
2. Commit all task changes using Conventional Commits, with the appropriate type such as `fix:`, `feat:`, `chore:`, `refactor:`, `docs:`, `test:`, or `build:`.
3. Push the task branch to the remote repository.
4. Create a pull request from the task branch into `dev`, never `main`.
